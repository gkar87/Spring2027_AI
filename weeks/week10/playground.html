How to use this page

  • In the Bayesian network, set any variable to observed true or false and read the updated probabilities of the others. In the HMM, add days with or without an umbrella and watch the belief move.
  • Each exercise has a Check answer button (or press Enter in a box). Numbers may be rounded to three decimal places or written as a fraction. Work them on paper first: the exams ask the same kind of question with no explorer to help.
  • Solved exercises are remembered in this browser only. Nothing here is graded.

A Bayesian network you can query

Four binary variables. Cloudy has no parents; Sprinkler and Rain each depend on Cloudy; WetGrass depends on Sprinkler and Rain. The explorer answers every query by enumeration: it sums the rows of the full joint distribution that agree with the evidence, then normalizes.

The network's conditional probability tables. A lower-case letter means the variable is true.

Filtering in a hidden Markov model

The umbrella world from the reading. Each day it rains or it does not; you see only whether the director brings an umbrella. Rain persists: P(rain tomorrow | rain today) = 0.7 and P(rain tomorrow | no rain today) = 0.3. The umbrella appears with probability 0.9 on a rainy day and 0.2 on a dry one. Day 0 starts at P(rain) = 0.5. Each day the filter predicts with the transition model, then weights by the sensor model and normalizes.

Exercises

Exercises 1, 5 and 6 are good practice by hand; do them on paper first.

Exercise 1

With no evidence, what is P(WetGrass = true)?

Hint

Sum over Sprinkler and Rain: P(w) = Σ P(w | s, r) P(s, r), and P(s, r) needs Cloudy.

Show a solution

0.647. With no evidence set, the explorer shows it directly; by hand, P(s, r) = Σc P(c) P(s | c) P(r | c), then weight by P(w | s, r).

Exercise 2

Observe WetGrass = true. What is P(Sprinkler = true | WetGrass = true)?

Hint

Set WetGrass to observed true and read Sprinkler.

Show a solution

0.430, up from the prior 0.3: wet grass is evidence for each of its causes.

Exercise 3

Now also observe Rain = true. What is P(Sprinkler = true | WetGrass = true, Rain = true)?

Hint

Add the second observation. Did the sprinkler become more or less likely?

Show a solution

0.195, lower than 0.430: explaining away. Rain already accounts for the wet grass, so the sprinkler is less needed as an explanation. Sprinkler and Rain are dependent once their common effect is observed.

Exercise 4

Observe Cloudy = true and Sprinkler = true. What is P(Rain = true)? Compare it with P(Rain = true | Cloudy = true).

Hint

Try it with and without the Sprinkler observation.

Show a solution

0.8 both times. Given Cloudy, Rain and Sprinkler are independent: the fork Sprinkler ← Cloudy → Rain is blocked by observing Cloudy.

Exercise 5

In the umbrella HMM, start over and add one day with an umbrella. What is P(rain on day 1 | umbrella on day 1)?

Hint

Predict: 0.5 × 0.7 + 0.5 × 0.3 = 0.5. Weight by 0.9 for rain and 0.2 for no rain, then normalize.

Show a solution

0.45 ÷ (0.45 + 0.10) = 9/11 ≈ 0.818.

Exercise 6

Add a second day with an umbrella. What is P(rain on day 2 | umbrella on days 1 and 2)?

Hint

Predict from 0.818 with the transition model, then weight by the sensor model and normalize.

Show a solution

Predict: 0.818 × 0.7 + 0.182 × 0.3 ≈ 0.627. Weight: 0.627 × 0.9 = 0.565 and 0.373 × 0.2 = 0.075; normalized, 0.565 ÷ 0.640 ≈ 0.883.
