How to use this page

  • Change any number in the query, keys or values. Turn the √d scaling off, or set a causal mask, and watch the weights and the output change.
  • Each exercise has a Check answer button (or press Enter in a box). Numbers may be rounded to three decimal places or written as a fraction. Work them on paper first: the exams ask the same kind of question with no explorer to help.
  • Solved exercises are remembered in this browser only. Nothing here is graded.

The attention explorer

One attention head with dimension d = 2, one query and three tokens. The score of each key is its dot product with the query; scores are divided by √d, turned into weights by softmax, and the output is the weighted sum of the value vectors. Edit any number and the table updates.

Exercises

Do exercises 1 to 3 on paper first; the final exam asks for an attention output by hand.

Exercise 1

With the starting numbers (q = [2, 0], scaling on, no mask), what is the scaled score of key k1?

Hint

q · k1 = 2 × 1 + 0 × 0, then divide by √2.

Show a solution

2 ÷ √2 = √2 ≈ 1.414.

Exercise 2

What attention weight does key k2 get?

Hint

Scaled scores are √2, 0 and √2. Softmax: es ÷ the sum.

Show a solution

e0 ÷ (e1.414 + 1 + e1.414) = 1 ÷ (4.113 + 1 + 4.113) ≈ 0.108.

Exercise 3

What is the output vector?

Hint

Weights are about 0.446, 0.108 and 0.446. Multiply each value vector by its weight and add.

Show a solution

0.446 × [1, 0] + 0.108 × [0, 1] + 0.446 × [1, 1] ≈ [0.892, 0.554].

Exercise 4

Turn scaling off. What weight does k2 get now? Is the distribution sharper or flatter?

Hint

Unscaled scores are 2, 0 and 2.

Show a solution

1 ÷ (2e2 + 1) ≈ 0.063: sharper. Without dividing by √d, scores grow with the dimension and the softmax saturates, which shrinks its gradients; that is why the transformer scales.

Exercise 5

Turn scaling back on and set the causal mask so the query is token 2. What weight does k1 get?

Hint

Token 2 cannot see token 3, so only k1 and k2 compete.

Show a solution

e1.414 ÷ (e1.414 + 1) ≈ 4.113 ÷ 5.113 ≈ 0.804; k3 gets exactly 0.

Exercise 6

Reset, then change the query to q = [20, 0], ten times larger. What happens to the weights?

Hint

Multiplying every score by 10 widens the gaps between them before the softmax.

Show a solution

The weights go to about 0.5, 0, 0.5: a larger query (or a lower temperature) makes softmax approach a hard maximum, and k1 and k3 tie.
