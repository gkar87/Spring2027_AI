How to use this page

  • Set the discount, the noise and the living reward, then press One sweep to apply one round of value iteration, or run until the values stop changing. Arrows show the greedy action for the current values. Changing a parameter resets the values to 0.
  • Each exercise has a Check answer button (or press Enter in a box). Numbers may be rounded to three decimal places or written as a fraction. Work them on paper first: the exams ask the same kind of question with no explorer to help.
  • Solved exercises are remembered in this browser only. Nothing here is graded.

The value iteration explorer

The grid world from the week 6 slides: four columns and three rows, numbered from the bottom left, so the start square is (col 1, row 1), the +1 exit is (col 4, row 3) and the −1 exit is (col 4, row 2). Square (col 2, row 2) is a wall. A move goes where it was meant with probability 1 − noise, and to each side with probability noise ÷ 2; a move into a wall or off the grid stays put. Each move from an ordinary square earns the living reward; exits keep their value. One sweep applies the Bellman update to every square at once, using the values from the previous sweep.

More examples to try

Two more grid worlds with the same controls. The exits are +1 and −1, as above.

A cliff

A five-by-three grid: the bottom row between the start corner and +1 is three −1 exits. Run until the values stop changing with noise 0, then with noise 0.2, then set the living reward to −2.

What to notice

With noise 0 the arrows in the middle row point east, along the edge of the cliff. With noise 0.2 they point north: a slip could drop the agent off the cliff, so it takes the longer route along the top. At −2 every arrow in the middle row points south, into the −1 exits, and the start corner steps east into one: ending at −1 beats paying −2 a move.

A long hallway

Ten squares and a +1 exit at the east end. Set the noise to 0 and press One sweep, a few times.

What to notice

Each sweep reaches one square further from the exit: after one sweep only the square next to +1 has a value (0.9), after three sweeps three squares do (0.73, 0.81, 0.9), and so on. Value iteration needs at least as many sweeps as the longest path to a reward.

Exercises

Exercises 1 and 2 are worth doing by hand first, then checking with One sweep.

Exercise 1

With γ = 0.9, noise 0.2 and living reward 0 (the defaults), press One sweep once. What is the value of square (col 3, row 3), next to the +1 exit?

Hint

Before the sweep every ordinary square is 0. Moving east reaches the exit with probability 0.8.

Show a solution

Moving east: 0.8 × 0.9 × 1 + 0.1 × 0.9 × 0 + 0.1 × 0.9 × 0 = 0.72. No other action does better.

Exercise 2

After the second sweep, what is the value of square (col 3, row 2), the one below it?

Hint

Its best action is north. With noise, it slips east into the −1 exit with probability 0.1, and west into the wall with probability 0.1, which leaves it in place (value 0 after one sweep).

Show a solution

0.8 × 0.9 × 0.72 + 0.1 × 0.9 × (−1) + 0.1 × 0.9 × 0 = 0.5184 − 0.09 = 0.4284.

Exercise 3

Press Run until change < 0.001 with the defaults. What is the value of the start square (col 1, row 1)?

Hint

Reset first, then run. Read the bottom-left square.

Show a solution

About 0.491. It is less than 0.95 = 0.590, the value with no noise, because slips waste moves and each move is discounted.

Exercise 4

With the defaults, how many sweeps does it take until the largest change in a sweep is below 0.001?

Hint

Read the sweep count after Run until change < 0.001.

Show a solution

15. The error shrinks by at least a factor of γ = 0.9 each sweep, so fewer sweeps are needed with a smaller γ.

Exercise 5

Set noise to 0 (γ = 0.9, living reward 0) and run to convergence. What is the value of the start square now?

Hint

With no noise the shortest route to +1 has 5 moves; count the discounts.

Show a solution

0.95 ≈ 0.590: the agent reaches the exit square in five moves and then collects +1, discounted once per move.

Exercise 6

Set the living reward to −2 (γ = 0.9, noise 0.2) and run to convergence. What is the best move from square (col 3, row 2)?

Hint

Every move now costs 2. Compare a −1 exit now with several more moves at −2 each.

Show a solution

East, into the −1 exit. Living is so costly that ending the episode at −1 beats the expected cost of reaching +1; the arrows show the agent heading for the nearest exit of either sign.
