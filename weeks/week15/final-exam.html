What it covers

  • Modules 1–7 (about a fifth of the points): search and heuristics, games, MDPs, value and policy iteration, Q-learning and SARSA.
  • Modules 9–10: probability, Bayesian networks and independence, variable elimination, sampling, HMMs and particle filters.
  • Modules 11–12: generalization and evaluation, precision and recall, calibration, logistic regression, backpropagation, regularization.
  • Module 13: attention, transformers, positional information, how language models are trained and evaluated.
  • Modules 14–15: deployment and monitoring, fairness criteria and why they conflict, model cards, the NIST AI RMF.

The formula sheet: the last page of the exam

Search and games

  • A*: f(n) = g(n) + h(n); admissible h(n) ≤ h*(n); consistent h(n) ≤ c(n, n′) + h(n′).
  • Alpha–beta: best case O(bd/2), worst case O(bd).

Decisions and reinforcement learning

  • Bellman optimality: V*(s) = maxa Σs′ T(s, a, s′)[R(s, a, s′) + γV*(s′)].
  • Q-learning: Q(s, a) ← Q(s, a) + α[r + γ maxa′ Q(s′, a′) − Q(s, a)].
  • SARSA: Q(s, a) ← Q(s, a) + α[r + γ Q(s′, a′) − Q(s, a)], with a′ the action actually taken.

Probability and Bayesian networks

  • Product rule: P(a, b) = P(a | b) P(b). Bayes' rule: P(a | b) = P(b | a) P(a) / P(b).
  • Marginalization: P(a) = Σb P(a, b). Normalization: P(X | e) = α P(X, e).
  • Network factorization: P(x1, …, xn) = Πi P(xi | parents(Xi)). A binary node with k binary parents needs 2k numbers.
  • Forward filtering: f1:t+1 = α P(et+1 | Xt+1) Σxt P(Xt+1 | xt) f1:t.

Learning

  • Precision = TP / (TP + FP). Recall (TPR) = TP / (TP + FN). FPR = FP / (FP + TN). Accuracy = (TP + TN) / N.
  • Sigmoid σ(z) = 1 / (1 + e−z). Log loss L = −[y log ŷ + (1 − y) log(1 − ŷ)].
  • Gradient descent: w ← w − η ∂L/∂w. ReLU(z) = max(0, z), with derivative 1 for z > 0 and 0 for z < 0.
  • Softmax: softmax(s)i = esi / Σj esj.
  • Attention: Attention(Q, K, V) = softmax(QK⊤ / √dk) V. Causal masking sets the scores of later positions to −∞.

Useful numbers

  • √2 ≈ 1.414; 1/√2 ≈ 0.707; e0.707 ≈ 2.03; e1 ≈ 2.72; e1.414 ≈ 4.11; e2 ≈ 7.39.
