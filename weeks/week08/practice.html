Part A: concepts (24 points, 3 each)

Answer all eight in one to three sentences each.

  1. A1. Define a consistent heuristic. Explain why, with a consistent heuristic, f = g + h never decreases along a path.

    Answer

    h is consistent if h(n) ≤ c(n, n′) + h(n′) for every edge from n to n′, and h(goal) = 0. Along an edge, f(n′) = g(n) + c(n, n′) + h(n′) ≥ g(n) + h(n) = f(n), using the inequality once.

  2. A2. Classify the task environment of a program that plays online chess against a person, with a game clock: observable, deterministic, episodic, static, discrete, single or multi-agent. One word each, with a reason for the one you think is least obvious.

    Answer

    Fully observable, deterministic (strategic: the only uncertainty is the opponent's move), sequential, semidynamic, discrete, multi-agent and competitive. The least obvious is semidynamic: the board does not change while the agent thinks, but the clock does, so its score does.

  3. A3. Iterative deepening expands the top of the tree again on every iteration. Explain why its time is still O(bd), the same order as breadth-first search.

    Answer

    Most nodes of a tree are in its bottom level: level d has bd nodes and is generated once, level d − 1 twice, and so on. The total, bd + 2bd−1 + … , is at most (b/(b − 1))2 times bd, a constant factor (about 1.23 for b = 10).

  4. A4. In backtracking search for a CSP, the minimum-remaining-values heuristic chooses which variable to assign next, and least-constraining-value chooses which value to try. Why does one aim to fail early and the other to fail late?

    Answer

    Every variable has to be assigned eventually, so picking the most constrained one first finds a dead end before more work is built on top of it. Only one value per variable is needed, so the value to try first is the one most likely to lead to a solution, which is the one that leaves the neighbours the most options.

  5. A5. Every leaf of a game tree has a positive value, and every leaf value is replaced by its square. Minimax still picks the same move; expectimax may not. Explain why.

    Answer

    Minimax only compares values, and squaring positive numbers keeps their order, so every max and min picks the same child. Expectimax averages values, and an average is not preserved by a transformation that only keeps order: squaring rewards a risky child with one large leaf more than a safe one. Expectimax needs values on a scale where differences mean something, such as utilities.

  6. A6. Give two reasons to use a discount factor γ < 1 in an MDP, and say what can go wrong with γ = 1 when there is no terminal state.

    Answer

    It keeps the sum of rewards finite on an infinite horizon, and it expresses a real preference for reward sooner (or a chance the process stops). It also makes the Bellman update a contraction, so value iteration converges. With γ = 1 and no terminal state, returns can be infinite and different policies cannot be compared by their sums.

  7. A7. Q-learning is off-policy and SARSA is on-policy. Say what each one's estimate is the value of, when both follow an ε-greedy policy.

    Answer

    Q-learning's target uses maxa′ Q(s′, a′), so it learns the value of the greedy policy, whatever the agent actually does. SARSA's target uses the action the agent really takes next, so it learns the value of the ε-greedy policy it follows, exploration included.

  8. A8. An agent starts Q-learning with every Q value at 0 and ε = 0. Explain what can go wrong, and one change that fixes it.

    Answer

    With ε = 0 it always takes the greedy action; once one action earns a positive reward it keeps taking that action and never tries the others, which may be better. Fixes: ε-greedy with ε decaying over time, or optimistic initial values so untried actions look attractive until tried.

Part B: mechanics (36 points)

  1. B1. Search traces (10 points). The graph has start S and goal G. Use graph search: a node is expanded at most once, and the goal test happens when a node is expanded. Break ties alphabetically.

    The graph for B1: edge costs, and the heuristic value h of each node.
    EdgeCostNodeh
    S–A1S5
    S–B4A4
    A–C2B5
    A–E5C4
    B–D2D3
    C–D1E1
    D–G4G0
    E–G3

    (a) Trace uniform-cost search. Give the expansion order, the path found and its cost. (3)

    (b) Trace greedy best-first search, which orders the frontier by h alone. Give the expansion order, the path and its cost, and say in one sentence why it is not the cheapest. (2)

    (c) Trace A*. Give the expansion order and the path. Name the node that uniform-cost search expanded and A* did not, and say why A* could skip it. (3)

    (d) Show that h is consistent on the edges C–D and A–E, in both directions. Given that h is consistent on every edge, what does that guarantee about A* graph search here? (2)

    Answer

    (a) Frontier as node:g. Start S:0. Expand S: A:1, B:4. Expand A: C:3, B:4, E:6. Expand C: B:4, D:4, E:6. Expand B (B and D tie at 4; B first): D stays 4, because 4 + 2 = 6 is worse. Expand D: E:6, G:8. Expand E: G stays 8, because 6 + 3 = 9 is worse. Expand G. Order S, A, C, B, D, E, G; path S–A–C–D–G, cost 8.

    (b) S, then A (h 4 beats B's 5), then E (h 1), then G. Order S, A, E, G; path S–A–E–G, cost 9. Greedy ignores the cost already paid, so the 5 on A–E never counts against E.

    (c) Frontier as node:f. S:5. Expand S: A:1+4=5, B:4+5=9. Expand A: C:3+4=7, E:6+1=7, B:9. Expand C (C and E tie at 7): D:4+3=7. Expand D (D and E tie at 7): G:8+0=8. Expand E: G via E would be 9, so G stays 8. Expand G. Order S, A, C, D, E, G; path S–A–C–D–G, cost 8. A* never expands B: its f is 9, above the cost of the solution, 8, so the goal is reached first. Uniform cost expanded B because its g of 4 was small; the heuristic showed it was far from G.

    (d) C–D: h(C) = 4 ≤ 1 + h(D) = 4, and h(D) = 3 ≤ 1 + h(C) = 5. A–E: h(A) = 4 ≤ 5 + h(E) = 6, and h(E) = 1 ≤ 5 + h(A) = 9. With a consistent h, the first time A* expands a node it has the cheapest path to it, so graph search, which never reopens a node, still returns an optimal path.

  2. B2. Minimax, pruning and chance (10 points). The root is MAX. Its children P, Q and R are MIN nodes, each with three leaves, left to right.

    The game tree for B2: leaf values under each MIN node, left to right.
    MIN nodeLeaves, left to right
    P5, 9, 7
    Q6, 3, 15
    R8, 4, 2

    (a) Compute the minimax value of each MIN node and of the root, and the move MAX makes. (2)

    (b) Run alpha–beta from left to right. Give α and β where each cut happens, and list every leaf that is never evaluated. (4)

    (c) Now P, Q and R are chance nodes, each leaf with probability 1/3. Compute the expectimax value of each child and the move MAX makes. (2)

    (d) Explain why alpha–beta cannot be used unchanged on the tree in (c), and what extra knowledge about the leaves would allow some pruning. (2)

    Answer

    (a) P = min(5, 9, 7) = 5, Q = 3, R = 2. The root is max(5, 3, 2) = 5; MAX moves to P.

    (b) Under P nothing can be cut: P = 5, so α = 5 at the root. At Q, the leaf 6 gives β = 6 > α, so go on; the leaf 3 gives β = 3 ≤ α = 5, so 15 is cut: Q is at most 3, and MAX already has 5. At R, the leaf 8 gives β = 8; the leaf 4 gives β = 4 ≤ 5, so 2 is cut. Seven of the nine leaves are evaluated, and the root value is still 5.

    (c) P = (5 + 9 + 7)/3 = 7, Q = (6 + 3 + 15)/3 = 8, R = (8 + 4 + 2)/3 = 14/3, about 4.7. MAX now moves to Q, value 8: the 15 that pruning skipped is exactly what makes Q worth more on average.

    (d) An average can be changed by any one leaf, so no unseen leaf can be ruled out: the cut of 15 in (b) would give the wrong answer here. If the leaves are known to lie in a range, say 0 to 20, a partly evaluated chance node has an upper bound (the leaves seen plus the maximum for the rest), and the node can be cut when that bound is below α.

  3. B3. Learning updates (8 points). Use α = 0.5 and γ = 0.9 throughout.

    (a) Q-learning. Q(s, a) = 2. The agent receives r = 1 and lands in s′, where Q(s′, left) = 4 and Q(s′, right) = 6. Write the target, then the new Q(s, a). (3)

    (b) SARSA, the same transition. The agent's ε-greedy policy picks left as its next action in s′. Write the target, then the new Q(s, a). (2)

    (c) Monte Carlo. From state s, an episode earns the rewards 1, 0 and 2, then ends. Compute the return G from s, then the new V(s) if V(s) was 1. (2)

    (d) In one sentence, why is SARSA's new value in (b) lower than Q-learning's in (a)? (1)

    Answer

    (a) Target = 1 + 0.9 × max(4, 6) = 1 + 5.4 = 6.4. New Q(s, a) = 2 + 0.5 × (6.4 − 2) = 2 + 2.2 = 4.2.

    (b) Target = 1 + 0.9 × Q(s′, left) = 1 + 3.6 = 4.6. New Q(s, a) = 2 + 0.5 × (4.6 − 2) = 2 + 1.3 = 3.3.

    (c) G = 1 + 0.9 × 0 + 0.92 × 2 = 1 + 0 + 1.62 = 2.62. New V(s) = 1 + 0.5 × (2.62 − 1) = 1 + 0.81 = 1.81.

    (d) SARSA backs up the action the policy actually took, an exploratory left worth 4, while Q-learning backs up the best action, worth 6.

  4. B4. Value iteration (8 points). Three states in a row: L, M and R. R is terminal and its value is fixed: V(R) = 10 in every sweep. In L there are two actions: stay earns reward 1 and remains in L; right earns 0 and moves to M. In M there are two actions: right earns 0 and reaches R with probability 0.8, staying in M with probability 0.2; left earns 0 and moves to L. Use γ = 0.5 and start from V0(L) = V0(M) = 0.

    (a) Compute V1(L) and V1(M), with the value of each action. (3)

    (b) Compute V2(L) and V2(M). (2)

    (c) Which action gives the maximum at L in sweep 1, and which in sweep 2? Explain the switch in one sentence. (1)

    (d) Solve for the exact V*(M) from the Bellman optimality equation for right, then find V*(L). (2)

    Answer

    (a) L: stay = 1 + 0.5 × 0 = 1; right = 0 + 0.5 × V0(M) = 0. V1(L) = 1. M: right = 0.8 × 0.5 × 10 + 0.2 × 0.5 × 0 = 4; left = 0.5 × 0 = 0. V1(M) = 4.

    (b) L: stay = 1 + 0.5 × 1 = 1.5; right = 0.5 × 4 = 2. V2(L) = 2. M: right = 0.8 × 5 + 0.2 × 0.5 × 4 = 4 + 0.4 = 4.4; left = 0.5 × 1 = 0.5. V2(M) = 4.4.

    (c) Stay in sweep 1, right in sweep 2. After one sweep, the reward at R has only reached M; in sweep 2 it reaches L through V1(M), and it is worth more than the steady 1 from staying.

    (d) V*(M) = 0.8 × 0.5 × 10 + 0.2 × 0.5 × V*(M), so V*(M) = 4 + 0.1 V*(M), and 0.9 V*(M) = 4: V*(M) = 40/9, about 4.44. At L, right is worth 0.5 × 40/9 = 20/9, about 2.22, and staying forever is worth 1/(1 − 0.5) = 2, so V*(L) = 20/9 and the optimal action is right.

Part C: proofs and arguments (20 points, two of three)

Each is worth 10 points. If you attempt all three, your best two count.

  1. C1. Let h1 and h2 be consistent heuristics, and h(n) = max(h1(n), h2(n)). Prove that h is consistent and that it dominates both. Then argue that A* with h surely expands no node that A* with h1 would not.

    Answer
    1. For an edge from n to n′: h1(n) ≤ c(n, n′) + h1(n′) ≤ c(n, n′) + h(n′), because h1(n′) ≤ h(n′). The same holds for h2. So h(n), the larger of the two, is also ≤ c(n, n′) + h(n′). At a goal both are 0, so h is 0. h is consistent. (4)
    2. h(n) ≥ h1(n) and h(n) ≥ h2(n) for every n by the definition of max, so h dominates both. (2)
    3. With a consistent heuristic, A* surely expands every node with f(n) < C*, and no node with f(n) > C*. If g(n) + h(n) < C*, then g(n) + h1(n) ≤ g(n) + h(n) < C*, so every node A* with h surely expands is one A* with h1 surely expands too. Ties at f = C* are the only exception. (4)

  2. C2. Let B be the Bellman optimality update, (BV)(s) = maxa Σs′ T(s, a, s′)[R(s, a, s′) + γV(s′)]. Prove that ‖BU − BV‖∞ ≤ γ‖U − V‖∞ for any U and V. Conclude that value iteration converges to a single V* from any starting values.

    Answer
    1. For any two functions f and g of a, |maxa f(a) − maxa g(a)| ≤ maxa |f(a) − g(a)|. (Say f's max is the larger, at a*: then the difference is at most f(a*) − g(a*).) (3)
    2. Fix s. The rewards cancel in the difference, so |(BU)(s) − (BV)(s)| ≤ maxa |Σs′ T(s, a, s′) γ (U(s′) − V(s′))| ≤ maxa Σs′ T(s, a, s′) γ ‖U − V‖∞ = γ‖U − V‖∞, because the probabilities sum to 1. Taking the max over s gives the claim. (4)
    3. B is a contraction for γ < 1. If BV* = V* and BW = W, then ‖V* − W‖ ≤ γ‖V* − W‖, so they are equal: there is at most one fixed point. Applying B k times from any V0 gives ‖Vk − V*‖ ≤ γk‖V0 − V*‖, which goes to 0 (the contraction mapping theorem gives existence). (3)

  3. C3. Prove that a CSP whose constraint graph is a tree, with n variables and domains of size d, can be solved in O(n d2) time without backtracking.

    Answer
    1. Pick any variable as the root and order the variables so that each one comes after its parent (a topological order of the tree). (2)
    2. For j from n down to 2, make the arc from Parent(Xj) to Xj consistent: delete every value of the parent that has no compatible value in Xj. Each arc costs O(d2), and there are n − 1 arcs: O(n d2). Working from the leaves up means a later deletion never touches an arc already made consistent below it. If a domain becomes empty, there is no solution. (4)
    3. Assign X1 to Xn in order. Each Xj has only one assigned neighbour, its parent, and the parent's value survived step 2 only because some value of Xj is compatible with it. So a consistent value always exists: no backtracking. This pass costs O(n d). (4)

Part D: design (20 points)

A city bike-share program wants an agent that decides, every 30 minutes, where its one rebalancing truck goes next and how many bikes it loads or drops there, across 40 stations. Riders take and return bikes unpredictably, and a station that is empty or full loses rides. The program has a year of trip logs and station counts and a simulator built from them that it only partly trusts. It cannot try risky policies on the live system at rush hour. It is judged on the number of lost rides each week.

  1. (a) Formulate (7). Define states, actions and rewards. Say whether this is best modelled as a search problem, a CSP, an MDP or a POMDP, and why. Name one thing your formulation leaves out.

  2. (b) Choose (6). Pick an approach from modules 1 to 7 and defend it against the strongest alternative. State the assumption your choice depends on.

  3. (c) Falsify (4). Describe the evaluation that would show you were wrong, including the baseline you would compare against.

  4. (d) Scale (3). The program grows to 80 stations and a second truck. Say what breaks in your approach first, and what you would change.

    What a full-credit answer looks like

    There is no single right answer. Here is one that would earn full marks, with the points each part is looking for.

    • (a) State: the bike count at each of the 40 stations, the truck's location and load, and the time of day and type of day. Actions: drive to station k, then load or drop j bikes, within the truck's capacity and the station's docks. Reward: minus the rides lost in the next 30 minutes, minus a small cost for driving. Demand is random but the counts are observed, so an MDP; a POMDP is also defensible if broken bikes or docks hide the true counts. Left out, for example: weather, events and holidays, which change demand.
    • (b) The state space is far too large for a table (40 counts at once), so value iteration on the full MDP is out. One good answer: Q-learning with function approximation, trained in the simulator on the year of logs, because there is no model to plan with but there is a place to practise. The strongest alternative is online lookahead: expectimax or Monte Carlo tree search a few steps deep with sampled demand, replanned every 30 minutes, which needs no training but needs the simulator at decision time. Either choice depends on the simulator's demand being close to the real one.
    • (c) Replay weeks held out of training, and compare lost rides against the program's current rule (for example, go to the station nearest to empty or full) and against doing nothing. If the agent does not beat the current rule on held-out weeks, or wins in the simulator and loses in an off-peak pilot, the simulator assumption was wrong.
    • (d) The joint action of two trucks is the product of their choices, and a learned value for the joint state needs far more data. Split the city into two zones with one truck each, or let the trucks choose in turn, each treating the other's plan as fixed.

    Marks go to the argument: a formulation that is stated precisely, a choice tied to the structure of this problem, and an honest test. A list of algorithm names earns little.
